# 창업메이트 (changupmate.com)

**사업 아이템을 적는 순간, 맞춤 창업지원사업이 실시간으로 뜨는 서비스.**

🌐 **https://changupmate.com**

## 주요 기능

- **실시간 아이템 매칭** — 사업 설명을 타이핑하는 즉시 K-Startup(창업진흥원) 모집 중 공고 300여 건에서 맞춤 공고를 스코어링해 표시. 왜 매칭됐는지 키워드 근거와 매칭 강도까지.
- **AI 분석 (Gemini)** — 입력 내용(링크 포함 — 실제 페이지를 읽음)에서 정확한 키워드·업종을 추출하고, 캐릭터가 분야 맞춤 멘트를 던짐.
- **공고 상세 드로어** — 실제 사업 사이트 첫 화면 미리보기, 초 단위 마감 카운트다운, AI 집중 포인트(빨간 한 줄), 주요 지원사항 요약, 신청방법·담당자.
- **글로벌 프로그램** — Devpost 오픈 챌린지를 영문 키워드로 매칭 (소스 확장 구조).
- **구글 로그인 게이팅** — 비로그인 시 상위 2건 미리보기 + 무료 사용 한도.
- **저장** — 마음에 드는 공고와 내 아이템 설명을 저장/불러오기.
- **MCP 서버** — [`mcp-server/`](./mcp-server): 공고 검색을 Claude 등 AI 에이전트·터미널에 연결.

## 기술 스택

- **프론트**: React 19 + Vite + TypeScript (Vercel 배포)
- **AI**: Gemini 2.5 Flash (키워드 추출·분야 판별·멘트·공고 요약, url_context로 링크 열람)
- **데이터**: 창업진흥원 K-Startup 공공데이터 API (프록시 백엔드) + Devpost
- **디자인**: Laravel Cloud 무드의 미니멀 대시보드 (점 격자 캔버스 + 라인 아이콘)

## 로컬 실행

```bash
npm install
# .env.local 생성:
#   VITE_GEMINI_KEY=<Gemini API 키>   (없으면 로컬 키워드 매칭만)
npm run dev
```

공고 데이터 API는 기본적으로 배포된 백엔드를 사용합니다 (`VITE_API_BASE`로 교체 가능).
